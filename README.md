# MPV PRISM preview

Public preview of MPV PRISM by AMPATEK SCRIPTS, built for design review. This repository holds built demo files only; the source code is private.

| Wave | Link |
|---|---|
| Design Wave 2 (in progress): Contacts, the Phone app, call screens and Messages with emoji | [design-wave-2/](design-wave-2/) |
| Design Wave 1: the iOS shell: power, Lock Screen, passcode, Home Screen, status bar, island, notifications, Notification Center, Control Centre, app switcher, setup assistant (approved) | [design-wave-1/](design-wave-1/) |
| Design Wave 0: Style Tile, device profiles, frames, demo shell (approved) | [design-wave-0/](design-wave-0/) |

Tool: [device-check/](device-check/) reads a phone's screen size and safe areas, to check published reference values against a real device.

Open the link on a phone and add it to the home screen for full screen. Add `?perf=1` to the address for the performance overlay.
